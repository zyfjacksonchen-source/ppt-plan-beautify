来源：用户提供晨湾绿意版，第39页生产页、第40页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：用漏斗规模和画像一起定位主力人群及资产结构缺口。
- 检索词：消费者资产、AIPL、潜客兴趣购买、人群DNA
- 所需证据：人群阶段定义、去重规则、资产量和画像分母、统计时间。
- 不适用：不同阶段重叠/累计数据被直接相加，或兴趣人群被写成购买人群。
- 替换重点：同步替换漏斗、总量、DNA和画像图；PL合并含义须解释，原总量与各层示例不应直接套算。

Applicable Scenarios
适用场景
适用于品牌进行人群洞察、种草转化漏斗复盘、用户结构分析或目标用户圈定。也可用于消费者资产盘点场景中的背景呈现页或策略起点页。
Page Structure Interpretation
页面结构解读
左侧三层漏斗：对应AIPL模型中潜客人群（A）、兴趣人群（I）、购买人群（PL），用于呈现品牌在不同阶段用户的体量差异，适合结合各阶段策略展开。
右侧人群画像模块：通过性别、年龄、消费能力、消费风格及人群标签等维度描绘核心人群特征，内容丰富全面，适配多类品牌分析需要。
中央视觉焦点“人群DNA”区域：作为人群核心特征提炼区，可用于展示品牌主力用户的显著特征（如高占比白领、偏年轻男性等）。
Recommendations for use
使用建议
建议结合品牌后台或平台大数据更新人群比例和细分维度，可使用圆环图/柱状图等替代默认样式。
各项占比数字建议保留一个小数位，确保精确又易读。
适配多平台数据并列使用（如不同平台AIPL结构对比），可作为衍生模板扩展内容。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板用于分析品牌潜客、兴趣用户与实际购买人群的构成比例及人群画像特征，辅助品牌识别核心消费群体特征，为后续的营销投放与产品布局提供数据依据。
帮助品牌从人群结构出发，明确营销漏斗中的转化瓶颈，识别高价值用户群体特征，为种草策略、精准投放、人群标签系统构建提供决策基础。
