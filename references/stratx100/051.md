来源：用户提供晨湾绿意版，第109页生产页、第110页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：用兴趣与年龄两张平台TGI矩阵选择优先触达渠道和内容。
- 检索词：TGI矩阵、平台匹配、兴趣年龄交叉、媒体选择
- 所需证据：TGI分子分母与基准人群；平台同周期样本；兴趣及年龄分类。
- 不适用：把TGI当占比，或按年龄直接推定收入/家庭身份。
- 替换重点：所有232占位值替换；修正重复46岁以上行，统一色阶基准，画像结论须数据支持。

Applicable Scenarios
适用场景
适用于品牌进行广告投放决策、内容平台策略选择、用户画像洞察等分析场景，亦适用于策略提案、平台分发方案、媒介投放排期等模块的视觉支撑。
Page Structure Interpretation
页面结构解读
左侧为“兴趣维度TGI匹配”，按内容兴趣（如美妆、美食、娱乐等）维度，分析各平台用户的偏好强度；
右侧为“年龄维度TGI匹配”，展示不同平台用户在各年龄段的分布趋势；
页面下方则归纳各关键用户群体（如95后、都市白领、家庭用户等）的内容偏好特征与投放建议。
Recommendations for use
使用建议
建议根据品牌所属品类及目标人群，重点标注1-2个主力平台及高TGI圈层，突出优先投放方向；
可补充“内容类型建议”或“广告样式匹配”，提升实操参考价值；
在策略汇报中，建议与“预算分配”或“达人策略”模块搭配呈现，构建完整的媒介投放链路。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板适用于展示在不同平台投放中，如何基于用户画像（年龄段、兴趣偏好）进行内容及广告的精准匹配策略，借助TGI（目标群体指数）数据进行用户特征洞察与平台调性适配分析，辅助品牌优化平台选择与内容布局方向。适用于媒介策略制定、跨平台内容分发、广告投放优化等场景。
通过用户TGI数据分析，帮助品牌厘清“投什么内容”“投给谁”“投在哪”，实现内容与人群的精准匹配，提升投放ROI与内容触达效果，为平台选择与预算配置提供数据支撑。
