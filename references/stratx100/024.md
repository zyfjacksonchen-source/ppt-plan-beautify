来源：用户提供晨湾绿意版，第55页生产页、第56页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：按声量、销售和认知三个维度给出数据、问题、优化动作。
- 检索词：竞品差距、声量销量心智、搜索份额、用户评价
- 所需证据：同周期竞品搜索/GMV；市场分母；正负评价原文及采样范围。
- 不适用：只掌握本品牌数据仍画竞品排名，或情绪词无原始评论支撑。
- 替换重点：三栏独立替换并逐栏校验表格与文字；原多组销量/搜索数互相冲突，不能只改品牌名。

Applicable Scenarios
适用场景
适用于品牌自身或竞品在社交平台、电商平台上的表现评估，可用于制定声量提升、转化优化、用户认知强化等策略。
Page Structure Interpretation
页面结构解读
页面分三大模块：左侧为社交平台声量维度，中部为电商平台销售维度，右侧为品牌用户认知维度；
每个模块通过数据表现 + 问题诊断 + 优化策略构成分析闭环，便于快速定位问题并制定行动计划；
下方补充对各维度的策略建议，适合直接作为汇报页结论落地。
Recommendations for use
使用建议
建议将品牌自身数据用统一色调高亮，突出差异性对比；
可按需替换平台数据指标，如声量换成“提及量”或“互动量”、销售可展示“成交额”或“转化率”；
若用于品牌对比报告，可叠加时间维度（如季度、半年）进行趋势补充。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板适用于品牌对比竞品的市场声量、电商销量及用户心智的综合分析，帮助识别品牌短板并提出针对性优化策略，常用于品牌季度复盘、营销策略调整与用户洞察报告等内容。
帮助品牌从用户触达 → 用户购买 → 用户认知三大核心维度清晰识别自身与竞品差距，输出系统化的优化方向，支撑品牌在声量、销量和心智上的多维提升策略。
