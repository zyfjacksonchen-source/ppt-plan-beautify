来源：用户提供晨湾绿意版，第13页生产页、第14页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：区分站内内容到转化闭环与站外、线下增长触点，显示协同边界。
- 检索词：站内闭环、站外外溢、线上线下、全链营销
- 所需证据：各渠道职责、资源和承接入口；线下活动/支付触点执行记录。
- 不适用：项目仅站内运营，却需要虚构线下、出海或支付数据打通。
- 替换重点：围绕全链核心与全域外圈替换模块；没有的校园、商圈、出海模块删除或标成待规划。

Applicable Scenarios
适用场景
适用于品牌展示如何打通内容种草、智能推荐、精准投放、用户运营等模块，实现站内转化与站外种草协同闭环；亦适用于企业整体营销体系规划、全域触点覆盖分析等内容的结构化呈现。
Page Structure Interpretation
页面结构解读
中部为站内营销闭环模块，核心为“全链营销”逻辑，围绕内容触达、用户转化、促销策略等维度展开；外环展示电商平台logo，支持用户自定义填写。右侧与下方拓展为“全域营销外溢”，强调社交、商圈、办公楼、地铁等多元线下场景配合数字营销资源形成的外部增长合力。
Recommendations for use
使用建议
支持根据品牌实际渠道，将不同场域模块进行删减、替换或重组（如电商平台、自有社交平台、出海渠道等）。
建议结合每一场域的用户触达数据、广告转化率、内容渗透表现等数据维度进一步补充使用。
可配合品牌全年节奏或活动排期，作为节日/大促策略页或资源位投放页的铺垫。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板适用于品牌梳理“站内+站外”“线上+线下”全链路营销布局，强调营销全流程的多触点协同与转化提效策略。可用于全域经营策略复盘、品牌营销漏斗拆解、品效协同路径呈现等方向的汇报场景。
该页可清晰展示品牌从站内闭环营销走向全域场景覆盖的演化路径，体现品效合一、渠道协同的营销策略价值，强化品牌在全触点环境中的渗透力与增长能力。
