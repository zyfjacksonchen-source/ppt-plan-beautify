## 选用判断

- 页面任务：用类目访问曲线和人群购买曲线的时间差推导投放窗口。
- 检索词：行为节奏、访问购买错峰、品类人群趋势、投放窗口
- 所需证据：同时间粒度的访问/购买数据；平台品类及人群定义；预算约束。
- 不适用：没有连续时间数据却绘制趋势，或只凭相关性承诺ROI。
- 替换重点：四个决策维度与两张趋势图联动；明确观察窗口、目标人群和预算结论的证据，不补造预测。

Applicable Scenarios
适用场景
适用于投放节奏规划、目标人群触达排期、平台合作节奏分析等内容，尤其在大型活动（如双11、年中大促）前用于节奏模拟与策略制定。
Page Structure Interpretation
页面结构解读
上方为四大决策模块：平台、品类、目标人群与行为维度，建议根据品牌自身经营模型灵活替换；
下方左图“类目访问趋势”展示了不同品类人群访问节奏，右图“目标人群购买节奏”展示关键人群的购买活跃变化，两者结合可用于判定平台流量与用户行为的错配与机会；
底部为五步投放逻辑链条，呈现策略推导与应用路径，包括目标、策略、节奏、预算等关键动作指引。
Recommendations for use
使用建议
可用于节奏差异分析：如对比平台间或人群间“转化窗口”的变化，从而制定错峰投放策略；
配合内容策略拆解使用：分析哪类内容在特定时间段内更具影响力，可作为内容生产排期依据；
建议补充平台流量趋势或ROI预测模型，提升决策的精准度与可信度。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板用于帮助品牌识别不同平台、品类及目标人群的访问与购买行为节奏，通过对比趋势差异，为营销活动制定更具针对性的节奏与投放决策策略，提升资源投放效率与回报率。
通过对比不同品类与不同人群的行为节奏差异，协助品牌更科学地制定“何时投放”、“投给谁”、“投什么内容”三位一体的投放策略，提升营销链路效率，降低无效投放成本。
