## 选用判断

- 页面任务：展示品牌传播从单向曝光到产品种草再到搜索/互动/投放协同的升级。
- 检索词：社媒营销演进、传播时代、种草时代、整合营销
- 所需证据：各阶段实际定位、触点能力及客户升级背景；若复盘须阶段执行记录。
- 不适用：需要预热-爆发-沉淀排期；该解读页与生产页的结构描述不一致。
- 替换重点：以生产页1.0/2.0/3.0为准替换阶段和代表形式；不要按解读页误改成活动三期而仍声称原版复用。

Applicable Scenarios
适用场景
适用于品牌内容营销全周期策划、内容产出路径梳理、内容引爆链路分析、传播路径构建等场景。亦可用于代理商或平台进行内容打法沉淀与策略拆解展示。
Page Structure Interpretation
页面结构解读
页面按照“内容传播路径”进行三段式划分：前期预热 → 中期爆发 → 后期沉淀，每阶段标明策略关键词与对应动作，有助于明确内容节奏控制点。
中部关键路径通过箭头联动，展示内容流转方向及各阶段的主推动作，如种草、互动、UGC产出、转化承接等。
下方支持配合补充平台触点、对应内容样式（如短视频、直播、图文等），增强操作参考维度。
Recommendations for use
使用建议
可根据品牌资源情况替换各阶段关键动作，例如：新品首发可突出“内容铺排+话题发酵”，成熟品类可聚焦“口碑种草+社交裂变”。
支持结合数据表现补充指标（如播放量、互动率、UGC量、点击转化等），用于策略效果复盘。
建议搭配平台传播曲线、用户路径图等页面，呈现从内容到转化的全链闭环。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板聚焦品牌内容传播的节奏化运作方式，拆解传播“前中后”阶段的关键目标与动作，帮助品牌梳理内容如何从话题引爆、口碑沉淀到带动转化。适用于制定整合内容营销策略或进行内容投放复盘。
帮助品牌理清内容营销的节奏划分与策略主线，避免内容分散与投放无效，建立“前中后”系统化内容传播体系，推动内容资产沉淀与传播效率最大化。
