## 选用判断

- 页面任务：把预热、预售、爆发三阶段的内容、媒体、达人、货品和会员动作排在同表。
- 检索词：节点三阶段、主题媒介渠道、达人主播排期、预算
- 所需证据：活动日期、产品及主播资源、阶段预算、会员权益和任务负责人。
- 不适用：只有年度方向，没有节点/资源确认却写执行计划。
- 替换重点：日期、内容主题、达人及预算整列联动替换；修正原生错字，明确计划状态和阶段KPI。

Applicable Scenarios
适用场景
适用于节点营销策划、新品预热排期、达人协同活动方案制定、品牌投放资源排布等场景。
Page Structure Interpretation
页面结构解读
页面主轴为三阶段时间线（3.1–3.11 / 3.12–3.18 / 3.19–3.21）；
每阶段对应内容主题、媒介安排、种草KOL策略与渠道行动策略；
左侧板块作为补充信息区，提供主题营销、媒介种草策略与执行动作维度；
底部汇总预算配置、平台投放口径等核心执行指标，形成闭环管理逻辑。
Recommendations for use
使用建议
建议根据品牌资源节奏调整每阶段预算配比与内容输出密度；
可进一步补充不同阶段的核心KPI，如曝光量、点击率、互动转化率等；
若为团队协作版本，可增加“执行负责人”或“交付时间节点”以提升落地效率。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页梳理了覆盖“预售预热—预售期—爆发期”的三阶段营销节奏，围绕主题内容策划、媒体传播布局与渠道动作执行等核心要素，呈现节点活动的全流程运营策略，适用于大型节点或新品上市活动的前期排期规划、资源协同管理与预算配置参考。
通过结构化梳理活动时间节奏与内容/媒介/渠道三线联动布局，强化节点活动的策划统筹能力，帮助品牌在关键营销期实现资源高效配置与人群高效触达。
