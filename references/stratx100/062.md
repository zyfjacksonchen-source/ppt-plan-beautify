来源：用户提供晨湾绿意版，第131页生产页、第132页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：用六品类销售表现连接用户购选因素，再提出产品/价格/渠道动作。
- 检索词：品类GMV、款式材质场景、选品优先级、决策因子
- 所需证据：品类GMV及占比/增速定义；用户决策调研；商品属性。
- 不适用：将超过100%的原示例称GMV占比，或单凭销量推断偏好原因。
- 替换重点：先把原两组同名GMV占比改成真实不同指标；六品类总占比校验，右侧因子按品类重写。

Applicable Scenarios
适用场景
适用于品牌方、电商平台或代理团队在制定产品分层运营策略、内容匹配逻辑及品类差异化投放建议时使用。
Page Structure Interpretation
页面结构解读
左侧区域呈现六大品类（A-F）在不同阶段的GMV占比增长趋势；
右侧以用户购选关注维度展开“材质-风格-场景”三类偏好要素；
底部总结三类策略建议，包含产品推广、价格策略与渠道拓展路径。
Recommendations for use
使用建议
可结合不同品类的高增长点，反推内容选题的优先级及表现形式；
用户关注要素可拓展为“调研洞察-内容制作-产品标签”三位一体的策略落地；
页面右下角建议模块也可拆分应用至具体策略页或方案结尾总结部分。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页聚焦各大商品品类的销售趋势表现，结合GMV占比增长数据，辅助用户购选关注点（如材质、风格、场景等），提供三项核心营销策略建议，为品牌制定更具品类特征的投放节奏与内容运营策略提供数据支撑。
帮助品牌基于实际销售表现识别高潜品类，结合用户决策偏好，明确产品传播与内容差异化路径，从而提升内容投放与用户需求之间的适配效率。
