## 选用判断

- 页面任务：对照多品牌/产品线的大促阶段与资源释放日期。
- 检索词：大促排期、多品牌对照、预售返场、节点协同
- 所需证据：最新活动日期、各项目计划、直播/搜索/达人排期。
- 不适用：只需全年日历，或把上一年双11日期用作当前平台规则。
- 替换重点：替换总轴日期和每行区间；六行Logo对应实际品牌/品线，阶段边界和跨行对齐须检查。

Applicable Scenarios
适用场景
适用于电商平台大促周期的品牌营销节奏策划，包括但不限于双11、618、周年庆等节日大促活动；也可用于品牌方自有活动节奏的编排与复盘。
Page Structure Interpretation
页面结构解读
上方为关键节点时间轴，自10月10日预热启动至11月15日返场收尾，完整覆盖从蓄水到转化的核心周期；
中部为品牌营销阶段对照表，每一行代表一个品牌/项目/产品线的投放节奏，通过时间段与营销阶段的交叉展示，便于快速对比多品牌间资源释放节奏；
每个阶段均以“内容形式+主目标”明确区分，便于使用者结合策略方向填充所需任务模块。
Recommendations for use
使用建议
支持在“LOGO”处替换品牌名，也可扩展为产品线/品类/人群策略等多个维度；
可进一步嵌入阶段重点内容（如：达人投放节奏、搜索投放期、直播排期等）；
若用于协同汇报，可标注“资源释放优先级”、“流量支持情况”、“GMV目标”等字段，增强横向管理效率。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页适用于品牌在大型电商节日期间（如双11、618等）制定分阶段营销节奏的排期规划。通过标准化的“预热-预售-高峰-冲刺-返场”五阶段框架，协助使用者厘清内容引导、资源释放及投放时点之间的节奏关系，便于多品牌、多渠道的统一协同管理。
本页模板帮助品牌厘清营销周期中的重点节奏拆解逻辑，实现不同部门（内容、投放、运营）在关键时间点上的精准协作，有效提升资源统筹效率与节奏管控能力，是大促营销策略制定与复盘的核心工具页。
