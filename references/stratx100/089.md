## 选用判断

- 页面任务：提供五类搜索任务及详细词包，便于比较覆盖与优先级。
- 检索词：守攻拓抢破、SEM词表、搜索量竞争度、SOV
- 所需证据：真实关键词和搜索量周期、竞争指标、品牌/竞品实体、目标SOV。
- 不适用：只想概念策略页而没有词表，或把泛品类词误分为竞品品牌词。
- 替换重点：逐词审核类别，原竞品栏大量通用词需纠正；词表、阈值、说明一并替换，保持密集表格可读。

Applicable Scenarios
适用场景
适用于品牌制定搜索引擎营销（SEM）策略的场景，尤其是在进行新品推广、品类渗透、用户承接、品牌防御或竞品狙击等需求下，需制定系统关键词投放计划时使用。
Page Structure Interpretation
页面结构解读
页面采用“守-攻-拓-抢-破”五大关键词策略分类：守：品牌词投放，目标SOV ≥ 90%，用于提升品牌搜索承接度。攻：品类词投放，目标SOV ≥ 40%，用于用户认知强化与品类关联。拓：场景词投放，目标SOV ≥ 3%，联动高净值用户与生活场景标签。抢：竞品词投放，目标SOV ≥ 3%，通过抢占竞品词引流对比人群。破：泛类关键词投放，目标SOV ≥ 3%，扩展流量池，强化搜索覆盖。
每类关键词均展示了关键词内容、竞争强度、月均搜索量等指标。
Recommendations for use
使用建议
品牌应优先保障品牌词SOV占有率，确保已有认知流量不流失；
对应不同营销目的（引导认知、促转化、干预竞品），灵活匹配关键词组；
可联动第088页“人群兴趣定向”策略，实现兴趣触达后搜索转化的闭环。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页从品牌词、品类词、场景词、竞品词和泛品类关键词五个维度拆解SEM投放策略，匹配不同SOV目标要求，帮助品牌构建完整搜索承接体系，提升流量覆盖、点击转化及用户联想认知效率。
构建由品牌词到泛类关键词的全链路搜索投放架构，帮助品牌实现从认知防守到流量扩展的全面策略落地，有效提升投放ROI与用户认知路径管理能力。
