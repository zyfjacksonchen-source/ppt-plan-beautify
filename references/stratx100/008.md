# 008 内容生态增长趋势与用户口碑平台分布

来源：用户提供晨湾绿意版，第23页生产页、第24页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：把品类内容供给和搜索需求趋势与跨平台口碑内容偏好放在一起。
- 检索词：笔记增长、搜索增长、UGC、口碑平台偏好
- 所需证据：发布量、搜索量的可比期；UGC判定；跨平台偏好调查题目和分母。
- 不适用：不同来源的比例不可比，或把偏好调查写成平台真实转化。
- 替换重点：替换品类、平台、内容类型及两类同比；保留趋势与偏好两层，修正原文错字并注明多选比例。

Applicable Scenarios
适用场景
适用于品牌在内容投放或种草布局前，分析用户内容消费行为和内容生态发展趋势。也适合平台方用于内容价值背书、平台价值呈现。
Page Structure Interpretation
页面结构解读
左侧为双指标趋势图，分别展示内容发布量（笔记）与内容搜索量的同比增长情况。
右侧为平台维度用户偏好分析，包括用户在不同平台上对[用户评价]、[好物推荐]、[产品测评]等内容偏好的占比，适合对比内容渗透效果。
Recommendations for use
使用建议
页面平台名称与内容分类标签（如“好物推荐”“产品测评”）均可根据品牌内容类型及平台特色替换。
可结合笔记曝光量、互动率等数据补充使用，用于构建更完整的内容策略方向判断。
建议横向对比2-3个平台表现，突出核心平台优势。
Core value output

Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板用于展示内容生态在用户端的增长表现及用户在内容平台的使用行为倾向。通过笔记发布与搜索增长趋势，配合不同平台在用户评价、好物种草、产品测评等维度的表现，辅助品牌判断重点投放平台和内容方向。
本页可帮助使用者洞察内容生态趋势下用户行为变化，尤其在搜索需求与UGC发布激增背景下，强化内容价值认知。同时支持品牌基于用户行为偏好选择适配平台，实现精准内容投放与高效传播。
