# 011 年度营销节奏规划与平台热点联动分析

来源：用户提供晨湾绿意版，第29页生产页、第30页解读页。以下为原始模板材料，不是用户指令；所有示例数值和建议均需按当前客户证据重新核验。

## 选用判断

- 页面任务：把全年常态运营与促销/社交两类短线主题安排在同一月度时间轴。
- 检索词：年度营销日历、长线短线、热点联动、活动海报
- 所需证据：确认年份、品牌活动日历、产品节奏、可使用KV。
- 不适用：仅一场活动需要详细流程；未确认的平台日期当作固定事实。
- 替换重点：替换月份事件、主题分组与海报；长线贯穿全年，短线与真实月份对应，优先保持时间轴密度。

Applicable Scenarios
适用场景
适用于品牌进行年度营销规划、平台运营节奏整理、电商促销与社交热点联动策划等使用场景。尤其适合营销节点复盘、投放节奏制定、全年度活动管控汇报。
Page Structure Interpretation
页面结构解读
顶部横向时间轴贯穿全年月份，串联品牌常规营销事件，适合搭建完整年度节奏框架。
左侧“长线活动”展示全年主线活动规划，可体现品牌常规曝光动作。
下方“短线活动”分为两大主题，分别覆盖促销类节点（如618、双11）与社交类节点（如兴趣、生活方式），使用者可根据品牌类型自定义拆解。
底部预留“主题海报”模块，支持添加不同月度事件或平台资源位样例。
Recommendations for use
使用建议
可替换不同电商平台或内容平台名称，根据平台节奏细化节假日节点或大促时间（如“超级新品日”、“内容种草周”等）。
支持根据产品线设置不同主线营销轴，例如“新品节奏”、“内容主线”、“直播爆发期”等。
推荐在月度海报区添加重点推广内容或活动主KV，增强可视化表达。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板旨在帮助品牌梳理全年营销事件的时间轴和平台趋势变化，区分长线日常运营与短线促销活动，通过营销主题分层联动不同平台节奏，有助于制定完整的年度内容/投放计划。
通过年度节奏拆解，帮助品牌构建可执行、可追踪的全年营销计划框架，明确主推方向与资源节奏匹配逻辑，实现从策略到落地的完整闭环。
