## 选用判断

- 页面任务：并列两种达人组合方法：粉丝量级分工与核心/泛/跨圈垂类配比。
- 检索词：达人金字塔、垂类跨圈、Tier组合、品牌成长阶段
- 所需证据：达人库层级、受众匹配及TGI；品牌阶段、预算或数量分配依据。
- 不适用：把粉丝量级等同垂类，不区分两条资源配置轴。
- 替换重点：左右模型保留各自维度；重算阶段占比，明确按预算/人数/内容量，筛选建议落到可核查达人条件。

Applicable Scenarios
适用场景
适用于品牌在新品首发、大促节点、节庆爆发期或人群扩圈期的KOL投放策略规划；也可用于投放复盘或内容达人组合结构优化。
Page Structure Interpretation
页面结构解读
左侧为金字塔模型：依据KOL影响力等级划分为头部、中腰部、长尾博主，对应品牌增长不同阶段的投放目标与策略建议；
右侧为Tier组合策略表：从KOL所属垂类角度出发，结合品牌所处阶段，提供“核心垂类+泛垂类+跨圈层”的建议占比结构，适合进行达人投放资源分配规划；
底部补充Tier 2/3的筛选策略建议：支持进一步细化选择逻辑，如基于TGI、平台影响力或行业趋势匹配等。
Recommendations for use
使用建议
可结合品牌已有达人库或MCN合作资源，补充每一层级或垂类对应的达人名单；
建议在不同周期（冷启、成长期、成熟期）明确各阶段主目标，辅助搭配内容目标（引爆声量 / 扩展人群 / 长效转化）；
若使用方有明确预算，也可在模型下补充“投入占比”、“ROI评估”或“内容素材拆解”内容，增强模板实战价值。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页模板适用于品牌制定内容投放期KOL布局策略。通过“金字塔分层模型”与“Tier组合策略”双线展示，帮助使用者拆解不同营销阶段下的达人投放重心与垂类组合逻辑，为品牌实现引爆声量或精准渗透提供结构化参考。
本页帮助品牌搭建系统化达人投放策略框架，通过可视化分层与组合模型，提升KOL合作的目标清晰度与人群触达效率，为内容驱动型营销落地提供前置规划逻辑支撑。
