## 选用判断

- 页面任务：拆开内容触达/回搜等前链与进店/购买后链，并配置品牌不同主场打法。
- 检索词：回搜路径、搜索上下游、站外验证、前后链路
- 所需证据：用户行为/词包、内容触点、站外交易联接和归因限制。
- 不适用：仅站内数据却声称后链路购买已验证。
- 替换重点：替换上方多入口搜索路径及下方两品牌策略；保留前后证据边界，进店不等于购买。

Applicable Scenarios
适用场景
适用于品牌进行内容种草策略规划、用户搜索行为分析、内容投放路径梳理以及搜索广告优化时的路径参考模型。
Page Structure Interpretation
页面结构解读
页面分为上方“路径链路图”和下方“双路径机制”两部分；上方路径从内容互动→品牌搜索→产品搜索→购买决策，完整还原用户行为流转逻辑；
下方将前链路（心智种草）与后链路（交易转化）分区展示，便于策略拆解；
右侧展示了用户在品牌不同主场地的行为模式与内容偏好。
Recommendations for use
使用建议
建议配合第055页“搜索投放策略”与第059页“广告投放策略”联合使用，进一步细化品牌在SEO/SEM环节的内容排布与预算规划；
可将用户行为链路作为策略拆解起点，从路径节点设置不同内容标签与互动机制，引导用户流入品牌主阵地；
同时通过交易验证机制闭环追踪效果，优化后链路投放 ROI。
Core value output
核心价值输出
Page Interpretation and Application Guidelines
页面解读与应用指引
本页展示了用户在社交平台上的典型消费决策链路，从初始互动到搜索转化，通过内容、搜索、行为路径三大关键环节串联前链路种草与后链路购买，帮助品牌厘清用户认知与转化逻辑。
通过“内容-行为-搜索-转化”全链路的用户行为路径洞察，为品牌制定更精准的内容投放与用户运营策略提供科学依据，提升种草有效性与转化效率。
